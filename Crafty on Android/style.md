# Crafty on Android presentation

- Installer and management menu: plain English terminal text, native terminal
  background and foreground colors; no forced ANSI colors or terminal clearing.
- Titles: `=== Crafty on Android | Cellhasher ===` for installation and
  `Crafty on Android` for the management menu.
- Prompts state valid choices and show defaults in square brackets.
- Progress and failures remain visible in scrollback and persistent logs.
- No images, logos, remote fonts, or additional frontend assets.
- The web panel uses Crafty's upstream interface, themes, colors, and assets.
  This project does not customize that interface.
